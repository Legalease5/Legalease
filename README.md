

​LegalEase ⚖️📄
​Overview: AI-powered legal document generator that creates customized contracts and agreements instantly.  

​FEATURES
​Document Generation: Drafts Work Contracts, NDAs, and Rental Agreements with customized parties, dates, and terms.  
​Gemini AI Integration: Powered by Google Gemini 1.5 Pro to format accurate legal clauses.  
​Multi-Format Export: Download documents in .TXT, .DOCX, and .PDF formats with optional logo branding.  
​Real-Time Preview: Interactive interface for easy editing before exporting.  

​TECH STACK
​Language: Python 100%  
​AI Engine: Google Gemini 1.5 Pro  
​Architecture: FastAPI / REST API backend with Web UI frontend  

​PROJECT STRUCTURE
​ai_core/: Gemini API integration and prompt handling  
​frontend/: Web UI templates and form inputs  
​LegalEaseAPI/: Backend routing and export logic
